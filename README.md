## テンペディット（tempedit）

テンペディット（tempedit）を用いれば、一時的にエディターを起動することができます。  
AIのプロンプトを書くようなときや、一時的に長文を書くようなときに、便利なのかもしれません。

## インストール

```bash
$ npm install --global @kokiito0926/tempedit
```

## 実行方法

```bash
$ tempedit
$ tempedit | cat
```

```bash
$ tempedit --extension "md"
$ tempedit --name "example.md"
$ tempedit --template ./template.txt
$ tempedit --editor "vim"
```
